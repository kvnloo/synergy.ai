Editorial code

Earn the reader's trust.

01

Use the closest source.

We link to agencies, local organizations, datasets, and original documents. Commentary comes second.

02

Label what we know.

Reported fact, interpretation, and project hypothesis are different things. The page should make that obvious.

03

Measure the work.

A useful tool has a named user and an observable result. Code shipped is not the same as a problem solved.

04

Protect people before data.

We do not collect sensitive information because it might be useful later. Human safety sets the limit.
